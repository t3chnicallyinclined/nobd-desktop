# SDL / Steam gamepad mapping for the NOBD Controller (Branded HID mode, 1209:4E43).
#
# Makes the native NOBD Controller a proper "gamepad" in SDL apps and Steam
# (A/B/X/Y etc. labelled correctly) instead of a generic joystick. XInput mode
# needs no mapping — SDL auto-recognises the Xbox-360 identity.
#
# Buttons are exact from the hm-native HID descriptor + packer (report.rs):
#   b0..b12 = A B X Y LB RB LT RT Back Start L3 R3 Guide ; hat h0 = d-pad ;
#   left stick = a0/a1. Verified against the live device with the SDL Gamepad Tool
#   (a/b/x/y/back/start/dpad/lefttrigger confirmed).
#
# Load in an SDL app via SDL_GameControllerAddMappingsFromFile, or the
# SDL_GAMECONTROLLERCONFIG_FILE env var. Also submitted upstream to
# mdqinc/SDL_GameControllerDB.
